# Control de Asistencia

Plataforma web interna para apoyar la gestión de asistencia, planificación y procesos administrativos de la organización.

> [!IMPORTANT]
> Este es un proyecto privado y de uso interno. Su código, documentación y recursos no deben compartirse, copiarse ni distribuirse sin autorización.

## Descripción

La aplicación centraliza herramientas operativas relacionadas con el personal y facilita el seguimiento de información necesaria para la gestión diaria.

Por motivos de seguridad y confidencialidad, este documento no incluye detalles sobre la arquitectura, las reglas de negocio, los modelos de datos ni la infraestructura utilizada.

## Tecnologías principales

- Next.js
- React
- MongoDB
- Sass

## Ejecución local

### Requisitos

- Node.js
- npm
- Acceso autorizado a la configuración del proyecto

### Instalación

```bash
npm install
```

Solicita al responsable del proyecto las variables de entorno necesarias y guárdalas en el archivo local correspondiente. No publiques archivos de configuración ni credenciales en el repositorio.

Inicia el entorno de desarrollo:

```bash
npm run dev
```

La aplicación estará disponible en [http://localhost:3000](http://localhost:3000).

## Comandos disponibles

```bash
npm run dev      # Entorno de desarrollo
npm run build    # Compilación para producción
npm run start    # Ejecución de la compilación
npm run lint     # Revisión de código
```
